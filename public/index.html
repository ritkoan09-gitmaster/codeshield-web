Active Detection Vectors

7 Proprietary SAST Static Analysis Rules

1. AWS & Cloud IAM Credentials Critical Secret

Detects exposed AWS Access Key IDs (AKIA/ASIA) and secret access keys in source files.

2. GitHub / GitLab Personal Access Tokens Critical Secret

Identifies leaked fine-grained or classic tokens (ghp_, gho_, glpat_) and OAuth tokens.

3. Database & Secret Keys Critical Secret

Flags raw database connection strings, JWT signing keys, and hardcoded passwords.

4. SQL Injection (Interpolated Queries) SQL Injection

Matches direct string concatenation or template literals passed to database queries.

5. Plaintext HTTP & Insecure Endpoints Protocol Risk

Detects unencrypted HTTP URLs in production endpoints susceptible to MITM interception.

6. Dangerous Dynamic Execution (eval) Code Smell

Identifies eval(), Function() constructor, and unsafe dynamic execution patterns.

7. Technical Security Debt Code Debt

Scans for unaddressed TODO/FIXME markers tagged with security or temporary bypasses.

All 7 rules execute concurrently during archive upload
